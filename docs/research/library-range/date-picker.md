# DatePicker

## Job

Choose one date using a field or trigger and a calendar popup.

Observed family coverage: **11 / 15 implementation systems** (11 with a component source; 0 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Compose Calendar, DateField and Popover; offer an explicit modal presentation for constrained layouts.
