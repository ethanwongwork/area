# TimeField

## Job

Edit a time of day with locale and precision controls.

Observed family coverage: **8 / 15 implementation systems** (6 with a component source; 2 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Separate time-of-day from duration; offer segmented entry and a selectable time list.
