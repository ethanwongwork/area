# TreeSelect / Cascader

## Job

Choose values from a hierarchy in a popup or cascading columns.

Observed family coverage: **2 / 15 implementation systems** (2 with a component source; 0 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Reuse TreeView and Combobox; separate tree-with-checkboxes from column-by-column cascading selection.
