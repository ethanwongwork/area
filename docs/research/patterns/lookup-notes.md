# Lookup notes

Checked 2026-09-28. This is a bounded public-source survey. “Not found” means a result was not established at the stated locations, never that an ecosystem cannot implement it.

- Primer’s guessed `/product/patterns/` entry was not accessible through the web reader. The live layout navigation links to [UI patterns](https://primer.style/product/ui-patterns/), including navigation, onboarding, empty, loading and degraded states. Those individual pages were retrieved.
- [Atlassian patterns](https://atlassian.design/patterns/) returns a script redirect to `/rovo-ui`; the old `/patterns/forms/` path returned 404. Use [Rovo AI interaction guidance](https://atlassian.design/rovo-ui/ai-interaction-guidelines) and current [Form examples](https://atlassian.design/components/form/examples) and [Comment examples](https://atlassian.design/components/comment/examples). The root form/comment paths were empty in the web reader; the `/examples` pages were readable through ordinary public HTTP. No historic pattern text was invented.
- [Polaris patterns](https://shopify.dev/docs/api/app-home/latest/patterns) currently separates full-page templates from smaller compositions. This catalogue uses those App Home web-component pages, not retired React API assumptions. `latest` is a dated live reference; source-checks.json records the retrieved bytes’ hash.
- [Material canonical layouts](https://m3.material.io/foundations/layout/canonical-layouts/overview) was unavailable through the web reader. The readable [official Android canonical-layout guide](https://developer.android.com/develop/ui/compose/layouts/adaptive/canonical-layouts) explicitly attributes its layouts to Material guidance. Platform layout principles are used; no Android API is claimed as an Area component.
- Apple HIG HTML was a JavaScript shell. Attempts under `/tutorials/data/documentation/design/human-interface-guidelines/` and `/tutorials/data/documentation/humaninterfaceguidelines/` returned 404. The working official endpoint is `/tutorials/data/design/human-interface-guidelines/<slug>.json`; panels, sidebars and onboarding were read there. A dedicated `inspectors` page was not found; [Panels](https://developer.apple.com/design/human-interface-guidelines/panels) explicitly discusses inspector behavior. Each Apple source records its readable JSON URL.
- The shadcn sidebar collection exceeded the web reader’s response limit; [featured blocks](https://ui.shadcn.com/blocks) supplied named sidebar and dashboard examples, and [login blocks](https://ui.shadcn.com/blocks/login) supplied readable page code. The guessed `/examples/mail` page was not accessible. Inbox anatomy therefore uses Material list-detail guidance, not an asserted shadcn mail implementation.
- Untitled UI’s guessed `/react/marketing/hero-sections` page was not accessible. The linked page is [hero-header-sections](https://www.untitledui.com/react/marketing/hero-header-sections). Public page labels/descriptions are the evidence for page variants. No paid code was accessed and no install command was run.
- Exact full IDE, file-manager, Markdown-editor and AI-chat screen templates were **not found in the particular guidance pages used for those entries**. They are explicitly labeled Area compositions from supporting-pane, toolbar, resource-list, messaging and AI guidance. This does not assert that such templates are absent from every upstream repository or paid collection.
