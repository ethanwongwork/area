One library of visuals, beside any tool

Area becomes a file manager for everything visual. Folders hold elements. An element holds its own versions and alternate designs, and its files: guidelines, research, data and code. Open one and it is live: change it in the inspector, try alternates, and hand the result to whatever tool builds it. Everything below works; click around.

What this changes in the new brief

  1. Four places become one library. The brief had Systems, References, Connections and Activity. Systems, projects, campaigns and references become top folders in one tree. Connections move to Settings and to each system folder's inspector. Activity becomes the code tools in the full window and the feed in the panel.
  2. Step 0 keeps the coding parts. The brief parked the agent chat, Files, the terminal and the GitHub actions. Here they stay as the On its own mode, behind the Technical tools switch the app already has. The page editor folds into an element's live view.
  3. Sub-elements are new. Variants, alternates and versions sit in one strip under every element. Today they live in three places: component tiles, a project's explorations, and Versions.
  4. Files are new. Documentation entries, specs, tokens and code are already written for every component, in four places in the repo. Here they show as one list on the element, and people can add their own.
