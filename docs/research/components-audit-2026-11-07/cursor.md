# Cursor components audit (2026-11-07)

Read-only. I read Cursor 3.27.22's installed bundle on disk and did not launch Cursor or read any user data. The scratch
extracts are in `/private/tmp/claude-501/components-audit/`, not in the repo. I compared each value with
[area-inventory.md](area-inventory.md) and checked it against Area's source (`packages/react/src/components/*.tsx`,
`packages/styles/src/components/*.css`).

**Sources.** Every path is under `/Applications/Cursor.app/Contents/Resources/app/out/vs/workbench/`.

| Short name | File | What is in it |
|---|---|---|
| `DCSS` | `workbench.desktop.main.css` | The VS Code workbench parts Cursor ships |
| `DJS` | `workbench.desktop.main.js` | Settings defaults and the list styles generated at runtime |
| `GJS` | `workbench.glass.main.js` | Cursor's own React kit (`ui-*`, StyleX) |
| `GCSS` | `workbench.glass.main.css` | Cursor's readable classes (`cursor-settings-*`, `agent-*`, `inline-diff-*`) |

**How the kit's values were read.** The kit's classes are StyleX hashes (`ui-a0pgpu`), and their CSS is a string inside
`GJS`. I resolved each hash to its declaration from that string, so a cited value reads like
`GJS › Dialog.stylex.js sizeSm{width:320px}`. The module names are the bundle's own `L({"Name.js"})` keys.

**Cursor's tokens.**
- `--cursor-spacing-N` is N × 4px, so `6-5` is 26.
- Heights are xs 20, sm 24, base 28 and lg 32.
- Type is 11, 12, 13 and 14.
- The motion and type values are in [cursor-audit-2026-10-22.md](../cursor-audit-2026-10-22.md) and
  [system-gaps-2026-11-06](../system-gaps-2026-11-06/README.md); I don't repeat them here.

**Not verified.**
- Nothing was seen rendered. These are declared values only.
- The values of the colour roles (`--cursor-bg-quaternary` and the like) depend on the theme, so the tables give the
  role names.
- Area's own gaps were checked against its props and CSS, not in the running app.
