## Token comparison

Both environments use the defaults declared in generated `config.js`: theme=light, neutral=neutral, accent=indigo, ui=default, radius=standard, surface=outlined, motion=subtle. Compact changes only `ui=compact`. The maps are assembled as base → each selected axis → derived, matching [the emitter](https://github.com/ethanwongwork/area/blob/7dae828e7af1daf9d26b663d34335121156606f7/packages/tokens/src/emit/css.ts#L98); JSON structure comes from [emit/json.ts](https://github.com/ethanwongwork/area/blob/7dae828e7af1daf9d26b663d34335121156606f7/packages/tokens/src/emit/json.ts#L110).

Aliases and fallbacks resolve recursively. The resolver selects the light arm of `light-dark()`, evaluates dimensionally compatible calc/min/max/clamp/round, normalizes absolute CSS length/time units and RGB/hex colors, and handles generated sRGB color mixes plus oklab mixes with transparent. Relative units retain their units: no assumed root font size, viewport or element geometry. Equality is numeric to ten decimal places, not perceptual proximity. Zero lengths can equal unitless zero only in length categories; scalar zero remains distinct from time or opacity.

Each row has whole-declaration matches plus matches for each atom. An atom inside the dark arm is still compared as an isolated value against the requested light token maps; it does not describe the active light paint. Matching names are equality candidates across all token namespaces, not recommendations to replace a value with a semantically unrelated token. A match to one constituent does not make a shadow, border or calc recipe fully tokenized. Private component vars are intentionally unbound; such whole values report `unresolved` while their literal atoms are still checked.

- defaultLight: 1068 tokens; 0 unresolved generated tokens.
- compactLight: 1068 tokens; 0 unresolved generated tokens.

Unsupported/context-dependent expressions are preserved with reasons. “not-found” means no equal value found in the resolved token map, not proof that no equivalent browser-computed value exists. All generated tokens and their provenance are listed in JSON. No browser cascade, pseudo-state activation or inherited private-variable evaluation is claimed. Output is an inventory of authored declarations, including declarations later overridden by the cascade.
