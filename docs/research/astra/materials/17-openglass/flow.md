# GlassLook: value flow and role recipes

All OpenGlass links pin `4943bbfd5611fe211cccf4b50c384345468d635b`. Role labels are this audit's synthesis. Reading a property is not evidence that every state or every family reacts to it.

## Four different selections

1. **Design** is `liquid` versus `classic`. The provider defaults to liquid and chooses a soft radius when none is explicit. It also creates a fresh palette from its own inputs. [packages/react/src/theme.tsx:67–106](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/react/src/theme.tsx#L67-L106)
2. **Material** is `clear`, `regular` or `frosted`, a physical/optical record with thickness, IOR, dispersion, edge strength, bevel and frost. These are not the GlassLook presets. [packages/core/src/materials.ts:4–44](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/core/src/materials.ts#L4-L44)
3. **GlassLook** is a sparse object or one of five sparse presets: `liquid`, `frosted`, `clear`, `smoked`, `lensed`. Liquid is the empty object; a preset is not a complete reset. [packages/core/src/look.ts:41–101](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/core/src/look.ts#L41-L101)
4. **Palette** supplies semantic ink, accent, focus and radii. GlassLook is not an input to its contrast calculation. [packages/core/src/theme.ts:189–241](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/core/src/theme.ts#L189-L241)

## From input to paint

`theme.glass` → `createGlassLookTokens` → `--ogui-glass-*` on the provider → inherited CSS inputs → derived `--ogui-lg-*` at liquid design/tone boundaries → component selectors. Look tokens are sparse; computed color variables are not registered with @property in these definitions. Liquid registers only its numeric animated glint. Provider style wins locally; its React token record only copies style overrides for keys already in that record. ## Shared role recipes

These recipe IDs connect the forty entries to exact sources. They are descriptive audit names, not exported APIs.

**G — material shell (container/floating surface).** Glass emits tinted body, material-dependent filter and a four-lobe stack: directed bloom, inner lensing, contact cast, distant cast. Shared conic mask ring is CSS. clear/regular/frosted preserve different optical baselines; all eleven look inputs can affect the liquid result across the inline stack and ring. Classic material tokens do not consume the look multipliers, and recipe liquid rules are excluded by design. [packages/renderers/src/css.ts:142–209](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/renderers/src/css.ts#L142-L209) [packages/renderers/src/css.ts:212–297](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/renderers/src/css.ts#L212-L297) [packages/recipes/src/liquid.source.css:179–227](https://github.com/moekoelueker/open-glass-ui/blob/4943bbfd5611fe211cccf4b50c384345468d635b/packages/recipes/src/liquid.source.css#L179-L227)

**B — raised control.** Ordinary Button/overlay trigger/restore/ToggleButton: white transmission fill, pointer glint, inner lensing + bloom + two lift lobes, control-tier filter, mask ring. ## Nesting and renderer boundaries

A local Glass look establishes a new marked CSS boundary, while arbitrary local variables on a Button can miss already-resolved ancestor `--ogui-lg-*` values. Use provider/Glass boundaries for derivation; do not infer a per-component Look prop from arbitrary HTML style support. The public Button props and implementation expose no such typed prop.
