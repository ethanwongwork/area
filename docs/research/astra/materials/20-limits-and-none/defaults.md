# Restraint that belongs to None

D1 moves the earlier no-shadow/no-label-effects/Trace-container ceiling into None's defaults. It does not relax contrast, focus, fixed hover ink, semantics or preference fallbacks. D13 adds the more specific rule: **no automatic** decoration of glyphs or small text, with explicit opt-in for display and button labels. D16 keeps the content ink and geometry owned by other axes even when an optical text treatment is opted into. [REVIEW.md:120–123](https://github.com/ethanwongwork/area/blob/dbd57a9067e3d927b2bfb7a061db074eeaf48db9/docs/research/astra/materials/REVIEW.md#L120-L123), [REVIEW.md:147–154](https://github.com/ethanwongwork/area/blob/dbd57a9067e3d927b2bfb7a061db074eeaf48db9/docs/research/astra/materials/REVIEW.md#L147-L154).

## N1 — In-flow controls have no resting cast

**Encoded today:** DESIGN_SYSTEM explicitly says in-flow fields/controls have no shadow and reserves shadow-1 for raised thumbs. Button starts `--_shadow:none` and documents no shadow on any variant. Input's resting shell and soft variant explicitly use `box-shadow:none`. The compiled-CSS cohesion test demands shadowless fields. [DESIGN_SYSTEM.md:159–168](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/docs/DESIGN_SYSTEM.md#L159-L168), [button.css:49–56](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/button.css#L49-L56), [button.css:319–325](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/button.css#L319-L325), [input.css:43–66](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/input.css#L43-L66), [cohesion.test.mjs:82–90](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/react/tests/cohesion.test.mjs#L82-L90).

**None contract:** keep those existing declarations and behavior. Do not replace every `box-shadow` with none: field focus halos, raised thumbs, Card, docked Panel, floats and literal exceptions already have paint. Preserve current selectors, including focus and autofill paths, and the selected Surface preset.

**Other materials:** D1 permits a control's decorative relief/cast; required focus must remain independent. The existing shadowless-field test should remain a baseline/None check when implementation arrives. Add material-specific cases rather than deleting it or keeping an unconditional scan that makes D1 impossible. No test is changed in this report.

## N2 — Plain labels and glyphs by default

**Encoded today:** body text sets semantic foreground/font metrics; Field labels set type and `fg-default`; Button consumes its resolved foreground. These are positive examples of plain semantic text. There is **no global `text-shadow:none` rule or all-label no-effects test found** in the scanned production sources. The source search finds no `text-shadow:` declarations in packages/styles/src, packages/tokens/src or packages/react/src at this SHA. That is an absence observation, not a cascade guarantee for consumer CSS. [base.css:5–14](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/base.css#L5-L14), [field.css:20–28](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/field.css#L20-L28), [button.css:89–98](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/button.css#L89-L98), [source-search.json](source-search.json).

**None contract:** add no text/gloss/glow/engraving/gradient-glyph treatment and preserve original computed ink, SVG geometry and text shaping. Do not add a blanket `filter:none`, `text-shadow:none` or `background-image:none` reset to every descendant: that can erase an existing functional effect or an explicit consumer style. For example ColorPicker's band edge already has a functional drop-shadow filter. [color.css:374](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/color.css#L374-L374).

**Other materials:** automatic host-wide effects that leak onto ordinary text/glyphs are still barred by D13. An explicit display/button-label treatment may add optical effect paint around unchanged ink; it must not rewrite foreground, type size/weight or glyph geometry. A label gradient that replaces the semantic ink is not admitted solely by calling it a material. Duotone needs the later pilot. A separate ink/type bundle is subject to D16, not a loophole in Material.

## N3 — Quiet containers, not a universal Trace cap

**Encoded today:** Surface describes restrained close shadows; Card consumes a faint measured halo, removes its halo in dark, and paints an opaque surface ground. In current main, Elevated Card restores its dark edge with an outline when Surface removes the decorative frame. Those details are part of today's identity. [surface.ts:1–18](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/tokens/src/axes/surface.ts#L1-L18), [surface.css:65–74](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/surface.css#L65-L74), [surface.css:100–111](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/surface.css#L100-L111).

There is **no production Material amount or numeric Trace cap found**. The blanket “containers at most Trace” was research policy, now explicitly superseded. It is not a literal Area CSS setting. The binding review names the mistake; task 19 preserves the old proposals with decision callouts. [REVIEW.md:17–36](https://github.com/ethanwongwork/area/blob/dbd57a9067e3d927b2bfb7a061db074eeaf48db9/docs/research/astra/materials/REVIEW.md#L17-L36), [19-corrections/README.md](../19-corrections/README.md).

**None contract:** preserve each existing container's actual fill/alpha, border, shadow, nested body and state wash, rather than flattening everything to a new uniform quiet container. Some container-role records are layout-only; None does not invent a painted box around them. The role map is context, not a CSS reset list.

**Other materials:** D1 allows stronger shells, including rich containers, while content contrast and semantic states remain hard limits. Numeric absorption strengths await calibration under D3. Do not reinstate no-blur-on-rows or a shadow-layer ceiling as an accessibility law; D14 requires measured performance policy.

## Existing exceptions must remain visible in None

None is independent of Surface, including Flat, Outlined, Raised and Elevated. The Surface axis defaults to Outlined; Flat currently removes token elevation but does not remove all literal component shadows. Toolbar's bar has a literal multi-layer recipe, and Tooltip has a smaller literal shadow. None must preserve these too until a separately proven pixel-identical D2 migration changes their ownership. It must not confuse None with Surface Flat, Motion None or opacity zero. [surface.ts:21–82](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/tokens/src/axes/surface.ts#L21-L82), [toolbar.css:20–35](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/toolbar.css#L20-L35), [surface.css:1395–1401](https://github.com/ethanwongwork/area/blob/d455567e5b264a768f42dc853476f1622ed6dd9f/packages/styles/src/components/surface.css#L1395-L1401), [REVIEW.md:124–127](https://github.com/ethanwongwork/area/blob/dbd57a9067e3d927b2bfb7a061db074eeaf48db9/docs/research/astra/materials/REVIEW.md#L124-L127).
