# Shared preset contract

**Proposal only.** The eight names select authored recipes, not verified vendor matches, implementation defaults or owner-approved designs. The controls follow [07](../07-controls/controls.md), roles and caps follow [04](../04-role-map/README.md)/[05](../05-absorption/README.md), and techniques/fallbacks follow [03](../03-css-cookbook/README.md)/[08](../08-accessibility/README.md). Those input revisions and current Area constraints are [pinned in evidence.md](evidence.md). Every number introduced here or in the data is an **authored trial seed**, unless the source-transfer ledger explicitly says otherwise. No image was measured.

## Reading a complete recipe

[presets.md](presets.md) is the readable role table. [presets.json](presets.json) expands eight presets × twelve roles × two modes: 192 complete requested control objects. Every object includes inactive leaves, so changing presets cannot retain an old glow, gradient or noise layer. `globalControls` is the floating-surface starting profile for editing; the complete role objects replace it. Do not cascade its blur onto children. `amount` is an ordinal cap, never a percentage or multiplier.

A mode means the existing Theme mode. It is not an extra Material dark-mode switch. Both modes use the receiver's actual semantic body, ink, focus and state sources. A preset does not change radius, size, density, font, layout, z-index, hit area, the role's relative depth or a component's completion status. Dark page remains the current near-black page. Switching Material cannot turn a layout-only wrapper into a painted container.

`receiver.body` and `receiver.ink` are proposed binding descriptors, **not existing CSS token names**. They resolve at the actual painted part, after tone/emphasis/theme scopes. Preserve its documented literal paint where the spec has one. `receiver.semantic-or-literal-core` means the existing progress, selection, status or literal color-data paint. `receiver.functional-occlusion` means the existing scrim or local fade. `body.source: none` adds no body; it does not erase the real glyph, text or divider. `transparency: 0` applies no extra transmission and preserves baseline alpha; a positive value multiplies the body's existing alpha by `1 - transparency`, never the whole element's opacity. If the base is not an opaque solid or the backdrop cannot be bounded, use F0 rather than guessing the composition.

The mode-specific role table is a request. The effective result is the strictest of preset, role, family, nesting, accessibility and actual geometry. An editor must show a suppressed request and its reason. None of these proposals confers contrast compliance without testing the composed result.

## All controls and ownership

Task 07 option A remains the recommendation: **Material beside Surface**. Material owns optional optical inputs under `--area-material-*`; Surface retains decorative border width and eligibility/source recipes for casts under its existing namespace and proposed `--area-surface-*` controls. Shared derivation in `emit/base.ts` would emit unregistered `--area-paint-*` outputs. No derived or paired color is registered with `@property`. Re-emit at relevant scope boundaries; replace complete preset and gradient stop lists atomically. A future React Theme material prop would select these records and validate patches as in [07 architecture](../07-controls/architecture.md), not expose raw serialized shadow strings as a second authority.

| Data controls | Layer / proposed owner | Complete interpretation |
| --- | --- | --- |
| `light.angleDeg`, `heightDeg`, `ambient` | illumination / Material | All recipes request 225° toward the upper-left, height 45°, ambient .5. 0° points right, 90° down. Shared per material scope, no RTL mirroring. Height is elevation angle, not CSS height. |
| `body.source`, `transparency` | body/transmission / Material | Semantic source above; values in the role table. No new color for functional content; no page/scrim transmission override. |
| `backdrop.source`, `mapping`, `blurPx` | acquisition / Material | `local` means one local CSS backdrop acquisition. `none` removes acquisition. Mapping is always unchanged: none of these presets requests displacement/refraction. Blur is a CSS-pixel input, not an equivalence to native optics. |
| `relief.profile`, `depthPx`, `softnessPx`, `spreadPx`, `strength` | intrinsic relief / Material | Flush, convex or concave, independent of DOM depth or cast tier. Local inset paint only, clipped before content; proposed finite light model below. |
| `surfaceControls.direction`, `liftGain`, `softnessGain`, `spreadDeltaPx`, `strengthGain` | cast / Surface | All presets preserve source direction, gains 1 and spread delta 0. They do not recolor, create or substitute a cast. A box-shadow used as a ring is an edge, not a cast. |
| `glow.source`, `strength`, `placement`, `spreadPx`, `softnessPx` | emission / Material | Only context-colored outer halos are enabled. `context` resolves the receiver's existing semantic source; ordinary neutral receivers use their existing edge source. Keep a distinct opaque readable core. No halo on literal data colors. |
| `gradients[layer]` | body reflection or edge / Material | Named linear layers, CSS angle convention, sRGB interpolation, percent positions and stable stop IDs. Other gradient kinds remain available through 07 but are off in these defaults. |
| `stroke.coverage`, `paint`, `profile`, `opacity` | decorative edge / Material, width / Surface | None/all coverage; solid/gradient paint; plain/double-rim/bevel profile. Existing decorative width is the total allocation, not the width of each rim. Solid paint uses the existing receiver edge source. Required boundaries/focus/invalid are independent and never attenuated. |
| `grain.source`, `strength`, `scalePx`, `seed`, `blend`, `clip` | texture / Material | One static monochrome tile, source-over, perimeter-only; see the deterministic proposal below. Scale is CSS pixels per texel. Strength 0 removes texture, not just its visibility. |
| `gloss.source`, `strength`, `extent`, `softnessPx`, `mask` | reflection / Material | Key-lit or authored top reflection, white at the stated alpha, width/height envelope below. Never over content. Reflection is separate from an emitted halo. |

Inactive leaves have defined neutral values in `neutralControls`; an inactive source name is not a request to allocate a layer. A zero strength, zero depth, absent gradient or `coverage: none` removes that channel. Static structure, source selectors and masks compile to named recipe rules; these are not all untyped CSS custom properties.

## Rendering interpretation for the authored seeds

This is a finite artistic rendering proposal, not physically based/native optics. The render order is: one allowed cast behind the owner; acquired backdrop under the body; body; local relief; static grain; named body reflection and gloss; optional decorative rim; optional emission around its emitter; content; required state/focus paint. Required boundaries remain independently identifiable. Clip decorative layers so they do not cover content or required cues. A cast belongs to one owner; arrows and edge aliases never add another copy.

For convex local relief, let `u = (cos(angle), sin(angle))`, `d = depthPx × cos(height)`. Use opposing inset-shadow offsets `-u × d` for the light-facing highlight and `+u × d` for shade; concave reverses these offsets. In CSS inset-shadow terms this puts the convex highlight on the light-facing inside edge. Both use the specified softness and spread. White is the highlight endpoint; black is the shade endpoint, each at `strength × (1 - ambient)`. They model only a clipped local rim, never alter body/ink tokens. Flush/depth 0 disables both. This added endpoint/offset model is an authored concretization of 07, not a claim about a vendor shader. Changing ambient reduces modeling without moving the light or washing the page. Existing Surface casts remain in their source direction even when intrinsic light changes: the compatibility option preserves current paint, rather than promising physical consistency.

Plain stroke consumes the existing decorative width `w`. Double-rim divides that same width into equal concentric outer/inner bands; it never adds `2w`. For a solid double-rim, use the ordinary edge paint on the outer band and the resolved local relief highlight on the inner band. A bevel uses the relief light/shade around that same allocation. A gradient double-rim divides the one sampled gradient's band, with the inner band using half its alpha; that factor is an authored seed. If `w = 0`, remove decorative stroke/rim. Relief remains local shading, but must not be used to recreate the disabled border. If there is no room for two distinct bands, use one plain rim; don't invent extra width. Raster quality of fractional bands is unverified.

Gloss is a white-to-transparent linear envelope over the light-facing side, ending at `extent × painted height`. `source: key` follows the key; `authored` in Aero is fixed to the top. For a key angle in screen coordinates, the CSS gradient toward the opposite side is `(angleDeg + 270) mod 360`; with the proposed upper-left key this fades toward the lower-right. Multiply alpha by strength, then restrict to the existing perimeter region excluding content. Aero's separate `body-reflection` gradient uses its own stops and full box coordinates, but is masked to the same safe perimeter region. It does not tint a label plate. If content reaches that region, omit the reflection there. No mask clearance is created by moving content.

Grain is a proposed reproducible 64 × 64 monochrome RGBA tile. Starting from unsigned state `seed`, advance `state = (1664525 × state + 1013904223) mod 2^32` once per texel in row-major order. Use white for a high bit of 1, black for 0, each at the requested strength; no channel color noise. Repeat at `64 × scalePx` CSS pixels, anchored to the optical owner's origin and shared by its children. It is fixed, never regenerated per frame. This algorithm and seed are **authored**, not a reproduction of WinUI's noise bitmap. Only Acrylic requests it; its perimeter mask excludes the reading plane. If that mask cannot be supplied, omit grain.

An outer glow uses the emitter silhouette as a mask with zero offset, the specified spread/blur and context color alpha. It is a separate halo rather than a filter on a whole subtree. It cannot enlarge the actual quantitative fill or spread across neighboring status marks. Where clearance/clip is unknown, omit it. A focused or invalid receiver suppresses this decorative halo while required state paint remains.

## Density, radius and absorption

Use [09 rules](../09-dark-density/rules.md). The dimensional seeds in these tables refer to a 32px painted raised control and a 16px painted thumb, both **authored reference boxes**, not measurements of all Area parts. For those roles only, `q = actual painted height / referenceHeightPx` scales local depth, local softness/spread and local glow softness/spread once. Do not also multiply by a compact-density factor. All other roles keep the listed local dimensional seeds fixed (`referenceHeightPx: null`), and fit/omit paint by their available perimeter; a very tall container must not acquire a proportionally huge blur. Backdrop blur, Surface casts, required strokes, angles, alpha, grain texels and gradient stop fractions do not scale with q. This fixed-shell choice completes the proposal where a universal reference height is not meaningful.

Use the existing **used** corner contour, including square, rounded, squircle where supported and pill. Inner contour is the concentric inset of the outer contour: for circular corners `max(0, R - inset)`. Never use the authored pill token's large number as a literal inner radius. At Sharp, keep mitered/square geometry, no optical rounding. At pill, cap bands to the actual local half-thickness. A native corner-shape path and a border-radius fallback are separate geometry implementations, not evidence of identical rendering.

No preset requests Full. Quiet permits a coordinated shallow relief/rim/reflection on a sparse shell. Trace retains one dominant decorative cue; required structural/state paint does not count as optional decoration. Lowering Quiet to Trace is structural, **not multiplying every alpha**:

- Paper retains its optional rim.
- Glass/Prism retain one edge gradient; drop blur, added transmission and gloss on repeated controls or dense reading surfaces.
- Acrylic becomes an opaque matte plane with a single optional rim; no grain or blur.
- Soft/Tactile retain one clipped signed local relief model (light/shade are a pair), dropping separate gloss and optional stroke overlays.
- Aero retains one perimeter reflection gradient, dropping body reflection and gloss.
- Glow retains one halo only on an isolated eligible emitter; dense controls/rows get None, retaining required state edges.

A mapped `edge` that aliases the parent shell uses the parent's resolved perimeter and does not evaluate a second recipe. The standalone edge row is for an independently painted edge part. Divider's structural line is unchanged; Soft/Tactile add only local paired relief where space permits. Keep all text and functional glyphs plain in every preset. No display-letterpress exception is enabled by selecting a preset.

Family guards in [05](../05-absorption/README.md) still apply: Table/Code/Message reading bodies remain opaque and flat; Calendar days/range joins keep their exact geometry; Slider keeps its track/handle/value paint and travel; InputGroup paints one shell; DatePicker opens a normal Calendar within one Popover owner. Transparent/ghost actions don't gain a resting body. Color data, progress extent and selection marks keep their actual values. Tooltip uses its existing opaque recipe and at most Trace. These are guard examples, not a substitute for the full 05 inventory.

## Nesting and states

Glass inside glass has one acquisition owner. Nested field/reading child is opaque; a separately opened popup is a new optical group and must evaluate its actual backdrop independently. Recessed in raised shares a key light; concavity uses its immediate body's resolved paint context and cannot accumulate darkening from every ancestor. Never instantiate per-row backdrop filters. Opaque reading islands are a requirement of the proposed Glass/Acrylic recipes, not an implication that the current components already provide such masks. If the necessary ownership/masks are unavailable, F0 is the complete effective recipe.

All seven states are listed for each preset. Apply pressed > hovered > resting body first, retain independent selected/checked/open meaning, then compose required focus/invalid. An additional material cue cannot be the sole state signal. “Existing body/edge” in the tables means existing receiver state paint; it does **not** request an unspecified numeric gain. Material alphas/stops stay fixed on hover. Soft/Tactile reverse the local relief sign only on eligible pressed controls; don't invert the surrounding panel. Aero press removes both gloss and body-reflection, while its required edge remains. Glow press sets optional halo strength to 0. Prism press removes only its optional gradient edge. No movement of labels or geometry.

Focus-visible and invalid suppress optional glow/gloss and all reflected body overlays; invalid also removes optional edge gradients. Required focus/invalid layers render above any surviving decoration. Disabled uses existing disabled paint once, removing all optional relief, emission, gloss, grain, gradients and decorative strokes. Do not dim children a second time or remove the underlying checked value. For transmitting receivers, use opaque disabled body instead of fading the entire composed panel. Open does not automatically “light up” its trigger: actual expanded state and the opened receiver's own role govern paint.

Do not animate blur, grain, gradients, shadow lobes or light. Material state changes are immediate proposed paint changes; existing Area state clocks remain owned by Motion. A reduced-motion request makes added material transitions zero (these presets add none). This avoids claiming interpolation quality that has not been measured.

## F0 and review gate

F0 means **the receiver's existing opaque semantic paint, required identification/focus/invalid paint, and existing permitted Surface cast**; remove Material transmission, acquisition, grain, gloss, gradients, relief and emission. Existing functional scrim opacity and intrinsic media remain functional, not forcibly made opaque. Forced colors uses the existing system-color mapping and suppresses optional effects/casts. Unsupported backdrop/masks, reduced transparency, uncertain backdrop or failed rendered contrast selects F0; stronger contrast can also select it. Don't emulate missing support with a more elaborate filter.

Before any production proposal, run all existing contrast tests unchanged, then add worst-case composed tests from [08](../08-accessibility/method.md): range of actual backdrops, intermediate colors/patterns, every required label/icon/boundary and focused/invalid/selected state, both modes, sizes/density/radii, nested scopes and supported browser fallbacks. Black/white backdrop endpoints alone do not prove all intermediary composites. Check required text and non-text ratios on their actual local adjacency; decorative contrast is not a substitute. The trial values here have **not** passed that gate. No browser visual claims or WCAG pass are made by this research deliverable.
