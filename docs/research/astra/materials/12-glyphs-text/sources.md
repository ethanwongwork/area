## Public primary documentation

- **S1:** [MDN drop-shadow()](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/filter-function/drop-shadow): alpha silhouette, two offsets and optional Gaussian standard deviation; no inset or spread. [W3C Filter Effects](https://www.w3.org/TR/filter-effects-1/#FilterProperty): ordered filter chain. Multiple drop-shadow functions process earlier results; they are not independent box-shadow lobes.
- **S2:** [MDN text-shadow](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-shadow): independent comma-separated shadows, first on top, offsets/blur/color. No inset/spread. Applies to text, not arbitrary SVG path strokes.
- **S3:** [MDN SVG stroke](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/stroke), [linearGradient](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/linearGradient), [gradientUnits](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Attribute/gradientUnits), [SVG 2 object bounding boxes](https://www.w3.org/TR/SVG2/coords.html#ObjectBoundingBox): CSS can override presentation attributes, gradients use referenced paint servers; user-space coordinates avoid per-part gradient extents and degenerate bounding boxes on horizontal/vertical lines.
- **S4:** [MDN feComposite](https://developer.mozilla.org/en-US/docs/Web/SVG/Reference/Element/feComposite), [W3C filter primitives](https://www.w3.org/TR/filter-effects-1/#FilterPrimitivesOverview): explicit alpha subtraction/intersection can build inward relief. SVG filter color processing defaults to linearRGB; record the chosen color-interpolation-filters space.
- **S5:** [MDN background-clip](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/background-clip): text clipping and readable fallback when the background image is unavailable. A transparent text fill alone is not a fallback.
- **S6:** [WCAG 2.2 understanding 1.4.3](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html), [1.4.11](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html): normal text and meaningful graphical information have different requirements. The conservative proposed test here additionally requires the undecorated core to pass; this is not a claim WCAG always forbids contrast-providing halos.
- **S7:** [MDN forced-colors](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/At-rules/@media/forced-colors): shadows/non-URL background images may disappear. Reset gradient paint and optional filters explicitly; don't assume all SVG filter decoration is automatically disabled.
- **S8:** [Apple WWDC21: What's new in SF Symbols](https://developer.apple.com/videos/play/wwdc2021/10097/): hierarchical/palette rendering uses annotated symbol layers. This is precedent for semantic coloring, not evidence that Area's arbitrary path order is an equivalent layer contract. HIG SF Symbols landing page also checked; its extracted content did not expose usable detail, so the accessible session is the cited source.
- **S9:** [MDN SVG as an image](https://developer.mozilla.org/en-US/docs/Web/SVG/Guides/SVG_as_an_image): distinguishes image embedding from SVG embedded as a document and records restrictions on external resources/stylesheets in image contexts. Host selectors on inline SVG are not an external-image part API.
