## New authored artifacts

`build.mjs` defines the twelve fixture compositions and all eight contexts. `specimen.js` binds actual parts to five active optical roles, reads exact preset values and applies guards; the other roles remain native or aliased as described in limitations. `specimen.css` supplies only `.m16-page`/`.m16-context` scoped rules. `backdrop.svg`, host spacing, comparison typography, slider ranges and the dark scene wash are authored lab presentation, **not** Area tokens or measured vendor values.

`verification.json` is browser evidence. Screenshots are visual inspection aids, never a source for numeric inference. `verification.md` separates repository tests, browser checks and untested cases.
