# FileUpload / DropZone

## Job

Choose or drop files and review acceptance and upload state.

Observed family coverage: **9 / 15 implementation systems** (9 with a component source; 0 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Compose a file trigger, drop target and file rows. Transport, virus scanning and persistence stay in the product adapter. The shadcn preview card is a visual analogue: its Browse button has no upload handler and is excluded from implemented-family counts.
