# DateField

## Job

Edit a date by named locale-aware segments, with text-entry alternatives distinguished.

Observed family coverage: **6 / 15 implementation systems** (5 with a component source; 1 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Build the segmented primitive before DatePicker; keep GOV.UK's separate day/month/year inputs as an alternative recipe.
