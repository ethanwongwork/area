# Tabs — library range

Baseline `7dae828e7af1daf9d26b663d34335121156606f7` · public references checked 2026-09-28. Counts and scope rules: [README-2](README-2.md).

## Job

Switches between views with transparent tabs and rounded indicators; labels align with panel content. [Area manifest](https://github.com/ethanwongwork/area/blob/7dae828e7af1daf9d26b663d34335121156606f7/packages/styles/src/manifest.ts#L593-L601).

Boundary: sm/md/lg underline with rounded indicator, optional track, both orientations, icons/counts, disabled and automatic/manual activation. Pill/enclosed treatments, overflow behavior and add/close contracts are not declared. [Area spec](https://github.com/ethanwongwork/area/blob/7dae828e7af1daf9d26b663d34335121156606f7/docs/specs/tabs.md#L1).

Each bundle count is a union (at least one listed alternative); exact individual counts are in [index-2.json](index-2.json).
