## Interaction patterns

Radix, Mantine and Polaris expose layout primitives. These do not create their own selection or dismissal contract; child controls keep normal keyboard order.

Evidence: [Radix Themes](https://github.com/radix-ui/themes/blob/1faff10ac26ae17f09944d418c6949b93fc6b566/packages/radix-ui-themes/src/components/flex.props.tsx#L1-L129), [Mantine](https://github.com/mantinedev/mantine/blob/f38933cb4f1c534600f4ff59ee3ddbb4685a4bc4/packages/@mantine/core/src/components/Grid/Grid.tsx#L1-L157), [Polaris](https://shopify.dev/docs/api/app-home/latest/web-components/layout-and-structure/grid).

Keyboard, selection, dismissal, loading and drag are separate contracts. Options below are only the declarations found in these sources; an absent contract is **not found**, not implicitly implemented by a visual composition. Static content inherits interaction from its child controls.
