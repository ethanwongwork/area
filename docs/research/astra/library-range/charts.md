# Chart integrations

## Job

Render quantitative information through a themed chart engine.

Observed family coverage: **8 / 15 implementation systems** (8 with a component source; 0 recipe-only). Apple HIG is checked separately as platform guidance. Counts are evidence-based lower bounds; see Sources.

Offer engine adapters with shared legend/tooltip roles and accessible alternatives; do not create a new plotting engine. Fluent evidence is its v9 charts package; Atlassian evidence is its Forge UI Kit chart extension, not an Atlaskit core chart. Availability is source-observed, not a release audit.

## Interaction patterns

shadcn and Mantine wrap chart engines. Carbon supplies chart families; Apple documents chart interpretation. Interaction, brushing and keyboard support are engine-specific.

Evidence: [shadcn/ui](https://github.com/shadcn-ui/ui/blob/db2db460a26fa84fb65c8d903b213925fbdee9ed/apps/v4/content/docs/components/base/chart.mdx#L1-L300), [Mantine](https://github.com/mantinedev/mantine/blob/f38933cb4f1c534600f4ff59ee3ddbb4685a4bc4/packages/@mantine/charts/src/AreaChart/AreaChart.tsx#L1-L300), [Carbon](https://github.com/carbon-design-system/carbon-charts/blob/26a7f620248caf53db3eaabd60df7f7ff44feb21/README.md#L1-L144), [Apple HIG](https://developer.apple.com/design/human-interface-guidelines/charts).

Keyboard, selection, dismissal, loading and drag are separate contracts. Options below are only the declarations found in these sources; an absent contract is **not found**, not implicitly implemented by a visual composition. Static content inherits interaction from its child controls.
