2. Title, status and primary action

**Common variations to catalogue.**

- Read-only detail.
- Editable sections.
- Primary content with auxiliary metadata.

**Extra requirements for expanded variants.**

- Editable title / text — **recipe**. Inline title editing can compose Input. No general display/edit wrapper with commit/cancel ownership found. [range cross-check](https://github.com/ethanwongwork/area/blob/7435813c947188664c665dc59f5fa0ffc5de4e8c/docs/research/library-range/editable-text.md#L97).

**Responsive proposal.** Move supporting metadata after the main content or into an explicit detail disclosure; maintain the page title and main action. General layout basis: [Fluent — Layout](https://fluent2.microsoft.design/layout).

**Behavior boundary.** A detail page is a composition. Property persistence, permissions and related-record loading remain application logic.

**Source observations.**

- [Polaris — Details template](https://shopify.dev/docs/api/app-home/latest/patterns/templates/details) (template; checked 2026-09-28). Individual resource viewing and editing uses a primary content column and supporting column.
- [Primer — Layout](https://primer.style/product/getting-started/foundations/layout/) (guidance; checked 2026-09-28). Defines header, content, supporting panes and footer; narrow list-detail views can become separate pages, auxiliary panes can become sheets, and summaries can stack.

**Common variations to catalogue.**

- Combined activity and comments.
- Separate history tab.
- Grouped daily events.

**Responsive proposal.** Keep events chronological in one column; expand dense metadata inline rather than creating a second timeline column. General layout basis: [Fluent — Layout](https://fluent2.microsoft.design/layout).

**Behavior boundary.** Proposed combination of comment examples and supporting content guidance. Ordering, attribution, timestamps and audit retention come from the product.

**Source observations.**

- [Atlassian — Comment examples](https://atlassian.design/components/comment/examples) (component-examples; checked 2026-09-28). Author/avatar, time, edited marker, body and actions; examples include nested replies and saving feedback.
- [Material — Canonical layouts (official Android guidance)](https://developer.android.com/develop/ui/compose/layouts/adaptive/canonical-layouts) (platform-guidance; checked 2026-09-28). Material-derived list-detail, feed and supporting-pane layouts preserve state as panes change visibility; editor tools and document comments are supporting-pane examples.
