Area against Cursor, ChatGPT (Codex) and Figma

Where Area is ahead

The design side. Settings that redraw every component, the inventory, versions with a change review, flows, direct editing and checks. None of the three coding apps has any of it, and Figma has no generator behind its variables.

Where Area is behind

The chat is real but it works in Area's own repository, not in the user's project. There is no folder per project, no preview of the user's running app, no view of what changed, and nowhere to send code except a folder.

What the three agree on

One shell: work listed in the sidebar, chat in the middle, and a side panel of tabs opened on demand (Changes, Files, Browser, Terminal, Plan). Figma Make has the same three: Browser, Files, Review.

What to take

The connection between chat and real code, and the small things that make a long agent run comfortable. The editor and the terminal as tools to switch on for technical people (owner, 2026-11-10), never the default; not the extension store. The brief already rules those out.

Build order

  1. Give every project a folder, and point chat at it. Everything else on the code side depends on this. T1 U4
  2. Show what changed. A Changes view with keep or undo per file, and a comment on a line that goes back to chat. T3
  3. Preview the running app, and point at it. The selection Area already has for its own designs, used on real code. T2
  4. Make Area the design contract for other coding apps. More MCP tools, a setup page, links that open Area. T7 U9
  5. Comfort for long runs. A finish notice, working marks on tabs, a command menu that runs things. T10 U1
  6. Smoothness. Panel motion, the slow Components scroll, error and loading states. V1 V3 V4
  7. Send to GitHub. Save, propose and ship in design words, once Changes exists. T4
  8. Technical tools, switched on. Files, a code editor and a terminal as side tabs for design engineers, off by default. T6

Proposals

Left out on purpose

  • An editor fork and an extension store. The brief says a purpose-built shell. A code editor and a terminal come as tools a technical person switches on (T6, owner 2026-11-10), not as the app's default face.
  • Chat, Work and Codex as three modes of one window. Area has one job. Ask, Suggest and Change already cover how far the agent may go.
  • Cloud agents, scheduled runs, PR inboxes, voice calls, pets, a menu-bar popout. Each needs accounts or a service Area doesn't have, and none helps someone make a design system.
  • Nine reasoning levels and a multi-model picker. Three models in one menu is the simpler interface.
  • Figma's infinite canvas, FigJam, Slides, Sites CMS. Already decided: each design lives in its own container.
