# Hand-coded drawing, 2026-11-10 (retired)

The first drafts of Area Serif, drawn from scratch in Python (`params.py`, `kit.py`, `glyphs.py`). Retired the same
day: the owner found the shapes inconsistent (serifs differed, gaps in the ink, curves not smooth) and asked for the
face to be built on one reference's real outlines. Area Serif is now derived from Libre Baskerville (OFL); see
`../../derive.py`. Kept for the record and for the alternate-form ideas shown on the options page; not built.
