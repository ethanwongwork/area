# Earlier project names — archived terminology audit

Area is the only current project name as of 2026-09-14.

- **Stadium:** appeared throughout the palette metadata, custom icon directories, source
  filter, SVG metadata, generated source identifiers, comments and design documentation.
  Current equivalents use Area, `area-icons`, `data-source="area"`, and `area-*` sprite IDs.
  Palette color values and icon geometry are preserved; only identifying metadata changed.
- **Visual Language Playground:** found in the old HTML title/header, old rule history
  and the previous repository URL recorded in a handoff. These files are archived.
- **Oval / 8x10 / 8×10 / Aerea / Aera:** no current project branding found under these
  spellings in tracked repository contents. Earlier commit messages remain historical.
- **Legitimate vocabulary retained:** Fluent's `oval` shape and `seat-multiple-stadium`
  glyph names identify objects, not this project. They remain upstream icon identifiers.
  Fluent, React and other third-party package names and attributions are not project aliases.

Git history was not rewritten, external repositories were not renamed, and dependencies
were not edited. Historical snapshots live under this archive and are not active rules.
